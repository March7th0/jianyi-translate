> 免翻墙的 Chrome / Edge 网页翻译插件:划词翻译、整页翻译、外语页自动提示、返回页面秒恢复。
> 有道 / DeepL / MyMemory 多引擎自动切换,**国内直连,无需代理,无需 API Key**。

## 功能特性

| 功能 | 说明 |
| --- | --- |
| 划词翻译 | 选中网页文字 → 点浮出的“译”按钮(或按 `Alt+T`),气泡显示译文,可一键复制 |
| 整页翻译 | 按 `Alt+P` 或点工具栏图标“翻译本页”,默认**仅译文**(可在弹窗切“双语对照”),完成后可一键**显示原文/译文**切换 |
| 秒恢复 | 翻译过的页面,再次打开(如从别的页面返回)自动从本地缓存恢复译文,无需重新翻译;手动“恢复原文”后不再自动恢复 |
| 自动提示 | 打开外语页面时自动弹出翻译提示条(谷歌式),支持“此站总是翻译 / 此站不再询问” |
| 极速批量 | 多行合并批量请求(实测逐行对齐),一次请求翻译 25 段,整页速度提升约 10 倍 |
| 快速翻译 | 点工具栏图标,输入文字即时翻译 |

## 翻译引擎(自动切换,全部免翻墙)

插件后台按顺序调用以下免费引擎,某一个被限流或不可用时**自动切换到下一个**:

| 顺序 | 引擎 | 特点 |
| --- | --- | --- |
| 1 | 有道翻译 | 速度快,支持多行批量;短时间大量请求会限流 |
| 2 | DeepL | 翻译质量高,支持长文本和更多语言;限速较严格 |
| 3 | MyMemory | 兜底引擎,保证出结果 |

> 引擎被限流后自动冷却并切换,失败条目会自动重试;提示“请求过于频繁”稍等几秒即可。

## 安装(3 步,无需上架商店)

1. 打开 Chrome,地址栏输入 `chrome://extensions` 回车
2. 打开右上角 **「开发者模式」** 开关
3. 点击 **「加载已解压的扩展程序」**,选择本仓库目录(含 `manifest.json`),完成

> Edge 浏览器同样可用:`edge://extensions` → 开发者模式 → 加载解压缩的扩展。
> 想翻译本地文件(file:// 打开的 HTML),请在扩展详情页开启“允许访问文件网址”。

## 使用技巧

- **划词**:选中文字后,文字上方会出现蓝色“译”按钮;也可以按 `Alt+T` 直接翻译。
- **整页**:`Alt+P` 是“翻译 / 恢复”开关;完成后点「显示原文」可随时来回对照。
- **自动恢复**:翻译过的页面再次打开自动恢复,可在弹窗关闭此行为。
- **修改快捷键**:打开 `chrome://extensions/shortcuts`。
- **弹窗「测试服务」**:一键检查三引擎链路是否可用。

## 常见问题

- **哪些页面无法翻译?** 浏览器自身页面(`chrome://`、设置页、新标签页)、Chrome 网上应用店等受保护页面无法注入;部分用 Shadow DOM 渲染的局部内容暂不支持。
- **为什么需要“读取和更改您在所有网站上的数据”权限?** 这是向网页注入翻译脚本所必需的(Manifest V3 的注入 API 要求站点权限),插件只在您主动触发翻译时访问页面文本,不收集任何其他数据。
- **翻译失败?** 各引擎均有免费限额,突发大量请求会限流;插件已自动限速、切换引擎并重试。弹窗「测试服务」可随时检查链路。
- **中文页面会翻译吗?** 会自动识别,页面文字已是目标语言时保持原文不重复翻译;简繁之间仍会互译。
- **隐私**:仅当你主动触发翻译时,所选文本/页面文本段才会发送到对应翻译服务器(有道/DeepL/MyMemory);翻译缓存只存在本机浏览器本地,不上传任何服务器。
